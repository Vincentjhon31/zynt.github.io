第四話

Total Concentration

Demon Slayers have breathing forms. These are mine — the four things I do on every system.

全集中
  1. 壱ノ型

    Read the paperwork first

    ARMS started with the office’s own Excel accomplishment reports, taken apart cell by cell before I drew a single screen. The system has to match the paper people already trust.

  2. 弐ノ型

    Keep it simple enough to keep running

    My rule for LGU work: as long as it is working and easy to use. Plain PHP and MySQL where they fit, Laravel when it earns its place — so the office can keep the system alive after I hand it over.

  3. 参ノ型

    Break it locally, not live

    Everything runs on XAMPP first, then ships to shared hosting through GitHub — wired so a push can’t land on top of the municipality’s live website.

  4. 肆ノ型

    Redo the design until it feels right

    Figma first, then real screens, then another pass when it doesn’t look right to the people using it. And every animation switches off for anyone who has reduced motion turned on — including the ones on this page.
